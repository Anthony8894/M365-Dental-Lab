# Microsoft 365 Admin Center

## Overview

The Microsoft 365 Admin Center is the main portal used to manage users, licenses, groups, and Microsoft 365 services.

In this lab, the Microsoft 365 Admin Center is used to manage the dental office environment.

## Common Tasks

The Microsoft 365 Admin Center can be used to:

* Create and manage user accounts
* Reset user passwords
* Assign or remove Microsoft 365 licenses
* Manage groups and distribution lists
* View active and deleted users
* Review service health
* Open other Microsoft admin centers
* Manage organization settings

## Other Admin Centers

The Microsoft 365 Admin Center provides access to other admin portals, including:

* Microsoft Entra Admin Center
* Exchange Admin Center
* Microsoft Intune Admin Center
* Microsoft Defender Portal
* SharePoint Admin Center
* Microsoft Teams Admin Center

Each admin center is used to manage a specific part of the Microsoft 365 environment.

## Use in This Lab

The Microsoft 365 Admin Center is used for tasks such as:

* Creating dental office employees
* Assigning Microsoft 365 Business Premium licenses
* Adding users to departments and groups
* Managing shared mailboxes
* Supporting user onboarding and offboarding
* Reviewing Microsoft 365 service health

## Access

The Microsoft 365 Admin Center can be accessed at:

```text
https://admin.microsoft.com
```

An account with the appropriate administrator role is required.

## Notes

Administrator access should only be provided to users who need it.

For more advanced settings, use the appropriate admin center instead of managing everything through the main Microsoft 365 Admin Center. Different portals can be found on the left hand side.
