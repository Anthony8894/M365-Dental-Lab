# Microsoft Defender

## Overview

Microsoft Defender is a security platform used to help protect users, devices, email, and company data from security threats.

In this lab, Microsoft Defender is used to simulate how a dental office could monitor and respond to security issues in a Microsoft 365 environment.

## What Microsoft Defender Can Be Used For

Microsoft Defender can be used to:

* Monitor security alerts
* Detect suspicious activity
* Review device threats
* Protect against malware
* Investigate security incidents
* Monitor risky users or sign-ins
* Review email threats
* Help protect Microsoft 365 accounts and devices

## Microsoft Secure Score

Microsoft Secure Score provides recommendations that can help improve the security of the Microsoft 365 environment.

Examples may include:

* Enabling MFA
* Improving device security
* Protecting user accounts
* Reviewing security policies

The score can be used as a guide to identify areas where security can be improved.

## Defender and Microsoft 365

Microsoft Defender works with other Microsoft 365 services such as:

* Microsoft Entra ID
* Microsoft Intune
* Exchange Online
* Microsoft 365 applications

Together, these services help administrators manage users, devices, and security from the Microsoft cloud environment.

## Lab Purpose

The purpose of using Microsoft Defender in this lab is to gain hands-on experience with security monitoring and threat protection.

The goal is to simulate common tasks that an IT administrator, help desk technician, or security analyst may perform in a Microsoft 365 environment.
