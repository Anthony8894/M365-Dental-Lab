# Microsoft Intune

## Overview

Microsoft Intune is a cloud-based device management service used to manage company computers, mobile devices, applications, and security settings.

In this lab, Intune is used to simulate how a dental office could manage company-owned Windows computers.

## What Intune Can Be Used For

Intune can be used to:

* Manage Windows computers
* View enrolled devices
* Deploy applications
* Configure device settings
* Apply security policies
* Manage Windows updates
* Require devices to meet security requirements
* Remotely manage company devices

## Devices in This Lab

Example device:

```text
DL-FRONTDESK-01
```

This computer represents a shared workstation used by employees in the Front Office department.

Additional devices may be added later for other departments.

## Planned Intune Tasks

Some tasks that may be completed in this lab include:

* Enroll Windows devices into Intune
* Create device groups
* Deploy Microsoft 365 applications
* Configure Windows Update policies
* Create compliance policies
* Configure security settings
* Test remote device actions
* Review device information and status

## Intune and Entra ID

Microsoft Intune works closely with Microsoft Entra ID.

Devices can be joined to Microsoft Entra ID and then managed through Intune.

This allows administrators to manage both the user account and the device from the Microsoft cloud environment.

## Lab Purpose

The purpose of using Intune in this lab is to gain hands-on experience with device management in a Microsoft 365 environment.

The goal is to simulate common tasks that an IT administrator or help desk technician may perform when managing company computers.
