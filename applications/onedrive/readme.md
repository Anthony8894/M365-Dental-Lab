# OneDrive

## Overview

OneDrive is Microsoft's cloud storage service. It allows users to store files online, access them from multiple devices, and synchronize files between their computer and Microsoft 365.

In this lab, OneDrive is used to simulate how an organization can store and protect user files while allowing them to access their data from different devices.

## What I Can Practice

* Signing users into OneDrive
* Syncing files and folders
* Backing up Desktop, Documents, and Pictures
* Using **Files On-Demand**
* Sharing files with other users
* Managing file and folder permissions
* Restoring deleted files
* Troubleshooting OneDrive sync issues
* Troubleshooting file path and file name issues
* Setting up OneDrive on a replacement computer
* Verifying that user files are successfully backed up

## Common OneDrive Locations

A user's synchronized OneDrive folder will normally appear in File Explorer as:

```text
OneDrive - Organization Name
```

Common folders may include:

```text
Desktop
Documents
Pictures
```

## Admin Tools

Depending on the issue, OneDrive can be managed or investigated through:

* Microsoft 365 Admin Center
* SharePoint Admin Center
* OneDrive web portal
* File Explorer
* OneDrive desktop client

## Troubleshooting

More detailed troubleshooting should be documented in the **Scenarios**.

This folder should focus on understanding and configuring **OneDrive itself**, while the Scenarios folder should document specific user problems and how they were resolved.
