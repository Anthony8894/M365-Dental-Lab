# Microsoft Outlook

## Overview

Microsoft Outlook is used to manage email, calendars, contacts, meetings, and shared mailboxes.

In this lab, Outlook is used to practice common Microsoft 365 tasks that an IT administrator or help desk technician may support.

## What Outlook Can Be Used For

* Send and receive email
* Manage folders and inbox rules
* Create calendar events and meetings
* Configure automatic replies
* Access shared mailboxes
* Manage mailbox storage
* Use Online Archive
* Troubleshoot Outlook synchronization issues
* Troubleshoot sending and receiving issues

## Outlook Administration

Some Outlook-related settings can also be managed through:

* Microsoft 365 Admin Center
* Exchange Admin Center
* Exchange Online PowerShell
* Microsoft Entra ID

Examples include:

* Creating shared mailboxes
* Assigning mailbox permissions
* Managing mailbox storage
* Enabling Online Archive
* Configuring retention policies
* Managing email aliases

## Folder Purpose

This folder should contain general Outlook documentation, notes, commands, and information about how Outlook works.

Example:

```text
applications/
└── outlook/
    ├── README.md
    ├── shared-mailboxes.md
    ├── online-archive.md
    └── outlook-commands.md
```

Specific user problems should be documented under the **Scenarios** folder instead.

For example:

```text
scenarios/
├── outlook-mailbox-full/
├── outlook-not-sending-email/
└── outlook-automatic-replies/
```

This keeps the Outlook folder focused on **how the application works**, while the Scenarios folder documents **how a real support issue was resolved**.
