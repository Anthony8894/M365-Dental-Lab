# PowerShell

This folder contains PowerShell commands, scripts, and troubleshooting steps that can be used to manage Windows computers and Microsoft 365.

## What is PowerShell?

PowerShell is a command-line tool that allows IT administrators to manage computers, troubleshoot problems, and automate repetitive tasks.

## What You Will Find Here

- Windows repair commands
- Windows Update commands
- Microsoft 365 administration commands
- User and computer information commands
- Basic PowerShell scripts
- Troubleshooting examples

## Purpose

The purpose of this folder is to document PowerShell commands that I have used and learned. Over time, I will add more commands and turn some of them into scripts to automate common IT tasks.

> Always review and understand a command before running it, especially in a production environment.
